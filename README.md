# Afghanistan Story Map

## [Link to the Map](https://ikoonat.github.io/afghanistan-story-map/) (Deployed on Github)

An interactive map application built with React, Leaflet, and Vite showcasing Afghanistan's geography and regions.

## Credits & Data Sources

This project uses data and resources from:

* **Province/Location Data**: [@tmaybe](https://github.com/tmaybe) - [Afghanistan GeoJSON](https://gist.github.com/tmaybe/5989042)
* **GIS Data**: [Simplemaps](https://simplemaps.com/gis/country/af) - Afghanistan GIS data
